# Pantry

Pantry is a self-hosted sundries tracker.

## Usage

```sh
git clone --recursive https://github.com/ayan4m1/pantry-compose.git pantry
cd pantry
cp .env.default .env
```

Change the default credentials to bespoke ones in `.env`.

```sh
docker compose up -d
```

Now the application is listening on port 8080.
